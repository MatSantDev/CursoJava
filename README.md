# CursoJava

Exercícios e projetos feitos durante o curso **Java COMPLETO – Programação Orientada a Objetos + Projetos** (Nelio Alves, Udemy).

## Conteúdo

Cada pasta em `src/Exercice/` é um exercício independente com sua própria classe `Main`/`Application`:

| Pasta | Tema |
|-------|------|
| `Poo` | Classes, objetos e encapsulamento (contribuintes pessoa física/jurídica) |
| `Composicao`, `Composicao2` | Composição de objetos (trabalhador e contratos; pedidos e itens) |
| `Enum` | Enumerações (status de pedido) |
| `Heranca` | Herança (contas bancária, empresarial e poupança) |
| `Polimorfismo`, `Polimorfismo2` | Polimorfismo e sobrescrita de métodos |
| `Abstract` | Classes e métodos abstratos (formas geométricas) |
| `Interface`, `Interface2` | Interfaces e injeção de dependência (aluguel de carros, parcelamento com PayPal) |
| `Exception`, `Exception2` | Tratamento de exceções e exceções personalizadas |
| `Files` | Leitura e escrita de arquivos, incluindo CSV |
| `Generics`, `Generics2`, `Generics3` | Tipos genéricos e coringas |
| `Set`, `Set2`, `Hashcode` | Coleções `Set`, `equals` e `hashCode` |
| `List` | Listas (funcionários) |
| `StringBuilder` | Manipulação de strings (posts e comentários) |
| `Matriz` | Operações com matriz organizadas em controller/service/view |
| `Criptografia` | Desafio de descriptografia de um texto lido de arquivo |

A pasta `subdir/` contém os arquivos de entrada e saída usados pelos exercícios de arquivos.

## Como executar

Abra o projeto no IntelliJ IDEA (ou outra IDE Java) e rode a classe `Main` do exercício desejado.

> Alguns exercícios de arquivo usam caminhos absolutos do Windows; ajuste o caminho para a sua máquina antes de rodar.

## Tecnologias

Java · IntelliJ IDEA
